✅ QUICK START (5 MINUTES)

  1. Copy 3 files to /DailyJournal/Analytics/
     • AnalyticsManager.swift
     • ScreenTrackingModifier.swift
     • SessionManager.swift

  2. Update DailyJournalApp.swift
     • Import FirebaseAnalytics
     • Initialize SessionManager.shared

  3. Add .trackScreen() to 5 main views
     • HomeView.swift: .trackScreen(.home)
     • JournalListView.swift: .trackScreen(.journal)
     • MirrorView.swift: .trackScreen(.mirror)
     • AuthContainerView.swift: .trackScreen(.authLogin)
     • OnboardingView.swift: .trackScreen(.onboarding)

  4. Run app → perform actions → check Firebase real-time
     Firebase Console → Analytics → Realtime tab

  5. You're live! ✅

🚨 RED FLAGS TO WATCH FOR

  DAU drops >50% in 1 day          → PAGE TEAM, DEBUG NOW
  Crash rate >5%                   → ROLLBACK LAST DEPLOY
  Funnel completion <30%           → A/B TEST ALTERNATIVE
  D7 Retention <15% for new cohort → CORE PRODUCT BROKEN
  Echo answer rate <30%            → FEATURE NOT RESONATING
  AI latency p95 >3000ms           → RATE LIMITED / CACHE NEEDED
